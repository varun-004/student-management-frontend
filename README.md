# Campus 360 — Frontend Portal

Modern web application for Campus 360, built with React, Vite, and Tailwind CSS.

## 🚀 Tech Stack
- React 19
- Vite
- Tailwind CSS
- Axios & React Router
- Lucide React

## 📌 Features
- Role-based views: Admin, Teacher, Student
- Course catalog & enrollment management
- Live attendance tracking & bulk marking
- Academic marks recording & GPA calculation
- AI-powered predictive risk analytics
